Mission

러닝을 시작하는 모든 사람 앞에, 오름직한 언덕이 됩니다.

For everyone who starts to run, we want to be a hill worth climbing.

Philosophy

i do nut run
for something.

무언가를 위해 달리지 않습니다.
달리기 위해 달립니다.

We don't run for something.
We run to run.

러닝은 더 빠르게, 더 멀리 가기 위해 발전해 왔습니다.
하지만 모두가 꼭 빨라지려고 달리는 건 아닙니다.

바람을 맞으려고 달리고,
몸을 움직이려고 달리고,
그냥 오늘 달리고 싶어서 달립니다.

가끔은 이유가 없는 게,
달릴 이유가 되기도 하지요.

그래서 do nut run은
러닝에 필요한 기능은 제대로 갖추고,
편안함과 개성은 조금 더 담았습니다.

달릴 때도 입고,
달리지 않을 때도 입을 수 있도록.

처음 러닝화를 신은 사람도,
오래 달려온 사람도
각자의 속도로 달릴 수 있도록.

do nut run은
러닝을 시작하는 모든 사람 앞에
오름직한 언덕이 됩니다.

Running has evolved to go faster and farther.
But not everyone runs to get faster.

Some run to feel the wind.
Some run to move their body.
Some run just because they feel like running today.

Sometimes having no reason
is reason enough to run.

So do nut run gets the running essentials right,
and adds a little more comfort and character.

Something to wear when you run,
and when you don't.

So that the first-timer in new running shoes
and the runner with years behind them
can each run at their own pace.

do nut run wants to be
a hill worth climbing
for everyone who starts to run.
